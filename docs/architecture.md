# 시스템 구조와 인터페이스

## 1. 입력 계층

카메라는 영상 기반 추론의 입력이며, 자이로와 가속도 센서는 차체 운동 상태를 읽는 데 사용됩니다. 예제의 `Pilot.Camera(width=300, height=300)`는 영상 입력 객체를 구성하고, `Pilot.AutoCar()`는 차량 제어와 센서 접근을 제공합니다.

## 2. 인식·학습 계층

| 인터페이스 | 예제에서의 역할 |
|---|---|
| `Pilot.Collision_Avoid` | 수집한 이미지 기반 충돌 회피 분류 |
| `Pilot.Object_Follow` | 객체 검출 결과에서 목표 객체 선택 |
| `Pilot.Track_Follow` | 영상에서 주행 목표 좌표 추론 |
| 데이터 수집기 | 영상과 라벨 또는 목표 좌표를 학습용으로 저장 |

객체 추종은 사전 학습된 검출 모델을 사용하고, 충돌 회피·트랙 추종 예제는 데이터 수집과 학습 과정을 포함합니다. 모델 선택과 데이터 수집 방식은 모듈별로 다릅니다.

## 3. 제어 계층

추론 결과를 차량에 바로 넘기지 않고, 콜백에서 조향값·전진·후진·정지 명령으로 해석합니다. 객체 추종 예제는 검출 중심의 가로 위치를 조향에, 객체의 상대 크기를 이동·정지 판단에 사용합니다. 이 상대 크기는 실제 거리 센서의 측정값과 구분됩니다.

제조사 예제의 숫자는 해당 실습에서 쓰는 설정입니다. 플랫폼 전체에 적용되는 안전 기준이나 검증된 제동 거리로 해석하지 않습니다.

## 4. 학습과 실행의 분리

데이터 수집 → 데이터셋 로드 → 학습 → 모델 저장 → 모델 로드 → 추론 콜백 → 차량 제어 순으로 연결됩니다. 하드웨어 API, 모델 파일, 카메라 장치가 함께 준비되어야 실행할 수 있습니다.
