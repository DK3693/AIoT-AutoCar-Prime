# 실습 모듈별 동작 분석

| 원본 예제 | 입력 → 처리 → 출력 | 기술적 관찰 |
|---|---|---|
| 8.1 Wheel Alignment | 자이로값 → 선형 회귀 → 조향 보정 | 센서와 조향값의 관계를 회귀로 표현 |
| 8.2 Posture Control | 자이로값 → 학습된 보정 관계 → 조향 | 주기적 센서 읽기와 제어 적용 |
| 8.3 Image Classification | 이미지 → 분류 학습 → 클래스 출력 | 데이터 수집과 분류 모델 사용 |
| 8.4 Voice Classification | 음성 → 분류 → 명령 해석 | 영상 이외 입력의 확장 |
| 8.5 Collision Avoidance | 카메라 → 분류 출력 → 전진/회피 | 분류 결과를 주행 상태로 전환 |
| 8.6 Object Follow | 카메라 → 객체 검출 → 조향·이동·정지 | 검출 위치와 상대 크기 기반 제어 |
| 8.7 Track Follow | 이미지와 목표점 → 학습 → 조향 | 지도학습 기반 주행 목표 추정 |
| 8.8 Traffic Cone | 카메라 → 목표점 추론 → 조향 | Track Follow 계열 인터페이스 활용 |
| 8.9 Line Tracer | 카메라 → 목표점 추론 → 조향 | 시각적 경로 추종 구조 |

## 객체 추종의 제어 흐름

1. `Object_Follow`가 지정한 객체를 검출합니다.
2. 가로 위치를 이용해 조향값을 계산합니다.
3. 검출 객체가 화면에서 차지하는 크기에 따라 이동 또는 정지를 선택합니다.
4. 목표가 검출되지 않으면 정지 분기로 연결됩니다.

## 학습 관점

동일한 차량 인터페이스 위에서 분류·검출·좌표 추정이라는 서로 다른 모델 출력을 제어 명령으로 연결할 수 있습니다. 모듈 비교의 핵심은 모델 이름보다 **어떤 입력으로 무엇을 예측하고, 그 결과를 어떻게 움직임으로 변환하는가**입니다.

원본 예제 파일의 기능을 요약한 문서이며, 예제 전체의 실차 완주나 정량 성능을 보고하는 실험 기록은 아닙니다.
