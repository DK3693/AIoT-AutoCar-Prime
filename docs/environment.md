# 환경 구성과 실습 순서

## 필요한 환경

- AIoT AutoCar Prime 차량 및 카메라·센서
- 제조사에서 안내하는 Jetson 소프트웨어 환경
- `pop` / `Pilot` 라이브러리와 하드웨어 드라이버
- Python·Jupyter, OpenCV/GStreamer 영상 입력 환경
- 사용 모듈에 맞는 모델 파일과 TensorRT 실행 환경

범용 PC에서 Python 패키지만 설치하는 방식으로 차량 예제를 실행할 수는 없습니다. SDK와 모델은 제조사의 배포 경로 및 장치별 설치 안내를 따릅니다.

## 권장 확인 순서

1. 장치와 SDK 버전을 확인합니다.
2. 정지 상태에서 카메라 프레임과 관성 센서값을 확인합니다.
3. 저속 제어가 가능한 공간에서 조향·구동·정지 인터페이스를 확인합니다.
4. 모듈별 학습 데이터의 입력과 라벨 구조를 확인합니다.
5. 추론값을 먼저 관찰한 뒤 제어 콜백에 연결합니다.

위 순서는 실습 내용을 이해하기 위한 체크리스트입니다. 이 저장소가 제공하는 자동 실행 프로그램이나 검증 완료 절차는 아닙니다.
